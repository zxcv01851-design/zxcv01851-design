### 🤖 Articlue AI Resume Matching System

LLM 기반 AI 이력서-채용공고 매칭 서비스

- 이력서 및 채용공고 데이터 분석을 통한 직무 적합도 평가 시스템 개발
- LangChain 기반 AI Pipeline 설계 및 구현
- HuggingFace Embedding과 ChromaDB를 활용한 벡터 검색 구현
- FastAPI 기반 REST API 개발
- LLM을 활용한 자기소개서 최적화 및 역량 분석 기능 구현

**Tech Stack**
`Python` `FastAPI` `LangChain` `LangGraph` `ChromaDB` `React` `MySQL`
